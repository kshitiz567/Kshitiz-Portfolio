### 🧠 Ask Kshitiz — AI Portfolio Assistant

The portfolio includes an interactive chat assistant powered by Groq.

Visitors can use it to learn about the projects featured on the portfolio and ask questions about my technical interests.


### How it works

A visitor submits a question through the chat widget.

JavaScript sends the question to the Flask backend.

The backend calls the Groq chat completion API.

The generated response is returned to the browser and displayed in the chat interface.

The assistant is designed to provide concise, professional answers without inventing qualifications or experience.
